# Bapun Interchangeable Spike Source Plan

## Scope
Update `[NeuroPy/neuropy/core/session/Formats/Specific/BapunDataSessionFormat.py](h:/TEMP/Spike3DEnv_ExploreUpgrade/Spike3DWorkEnv/NeuroPy/neuropy/core/session/Formats/Specific/BapunDataSessionFormat.py)` so `*.neurons.npy` is no longer a hard session requirement when `{session_name}.clusterless_spikes.npz` exists. At least one of those two spike-source files must exist.

## Current Behavior
`get_session_spec()` currently lists `{}.neurons.npy` in `required_files`, so `DataSessionFormatBaseRegisteredClass.build_session()` can fail during `SessionConfig` validation before the clusterless loader runs.

```624:629:h:/TEMP/Spike3DEnv_ExploreUpgrade/Spike3DWorkEnv/NeuroPy/neuropy/core/session/Formats/Specific/BapunDataSessionFormat.py
    def get_session_spec(cls, session_name):
        return SessionFolderSpec(required_files=[SessionFileSpec('{}.xml', session_name, 'The primary .xml configuration file', cls._load_xml_file),
                                           SessionFileSpec('{}.neurons.npy', session_name, 'The numpy data file containing information about neural activity.', cls._load_neurons_file),
                                           SessionFileSpec('{}.probegroup.npy', session_name, 'The numpy data file containing information about the spatial layout of recording probes', cls._load_probegroup_file),

                                           SessionFileSpec('{}.paradigm.npy', session_name, 'The numpy data file containing the recording epochs. Each epoch is defined as a: (label:str, t_start: float (in seconds), t_end: float (in seconds))', cls._load_paradigm_file)]
```

## Implementation
- Add a small class helper like `_has_required_spike_source(session_basedir: Path, session_name: str) -> bool` that returns true if either `{session_name}.neurons.npy` or `{session_name}.clusterless_spikes.npz` exists.
- Change `get_session_spec()` to remove `{}.neurons.npy` from `required_files` and include both `{}.neurons.npy` and `{}.clusterless_spikes.npz` in `optional_files`.
- Add `additional_validation_requirements=[lambda basedir: cls._has_required_spike_source(Path(basedir), session_name)]` so `SessionConfig` still rejects sessions with neither spike-source file.
- Add a file-spec compatible `_load_clusterless_spike_events_file(filepath, session)` that loads `ClusterlessSpikeEvents`, sets `events.filename`, and assigns `session.clusterless_spike_events`.
- Add a helper like `_try_load_optional_spike_sources(session, loaded_file_record_list)` that loads optional neurons if present, then loads optional clusterless if present. This keeps both available when both files exist.
- Update `_perform_spike_comps(session)` so flattened-spiketrain computation only runs if `session.neurons` exists. If no neurons exist but `session.clusterless_spike_events` exists, skip flattened-spike recomputation instead of touching `session.neurons`.
